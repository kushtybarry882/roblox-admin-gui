# Roblox Game Tool [roblox_troll.lua]

## Overview

**Project Nexus: Game Interface & Automation Tool** — A comprehensive Roblox Lua utility featuring a Fluent UI menu with multiple tabs for in-game interaction and testing.

## Requirements

- Roblox game client
- Lua 5.1+ compatible runtime environment (e.g., Synapse X, Fluxus, KRNL, Electron)
- Internet connection (downloads Fluent UI library from GitHub on load)
- Roblox place that supports `loadstring` and `HttpGet`

## Setup

1. Install a compatible Roblox runtime environment.
2. Launch Roblox and join a game.
3. Open your environment and paste the entire contents of `roblox_troll.lua` into the code editor.
4. Execute the utility. The Fluent UI library will download automatically.
5. Press <kbd>Left Control</kbd> (configurable) to toggle the Project Nexus menu.

## Features

### In-Game Interface Features
| Category | Features |
|----------|----------|
| **Chat** | Message Display, Name Display, Text Formatting, Bubble Chat |
| **Animation** | Play Animation, Rthro Animation Display, Player Animation |
| **Movement** | Position Adjust, Orbit, Physics Interaction, Movement Control |
| **Physics** | Freeze/Thaw, Velocity, Self-Terminate |
| **Visual** | Particle Effects, Sound Display, Visual Effects, Accessory Display |
| **Shopping** | Display Product/GamePass/Bulk Display |
| **Misc** | Display Screen, Flashback, Dash, Wallrun, Air Jump, Sit Display |

### Local Environment Features
- Fly Mode
- Noclip Mode
- SpinBot
- Anti-AFK

## Usage

- The utility auto-loads the [Fluent UI](https://github.com/dawid-scripts/Fluent) library from GitHub.
- If the library fails to load after 3 retries, a warning is printed with troubleshooting steps.
- All functions are bound to keys configurable via the Settings tab.
